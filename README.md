# WireGuard Desktop

macOS-клиент на Electron + React/TypeScript: параллельные туннели, редактор конфигов, handshake/трафик, строка меню с поповером, автоматическая светлая тема и View Transitions.

## Установка

Откройте `WireGuard-Desktop-0.2.2-arm64.dmg` и перетащите приложение в Applications / «Программы». Запускайте через Spotlight: **WireGuard Desktop**.

При первом запуске macOS один раз запрашивает разрешение администратора для установки системного помощника. После установки подключение, отключение, определение интерфейсов и статистика работают без повторных запросов пароля. При отмене можно повторить через «Настроить доступ».

Node runtime, Bash, wg, wg-quick и wireguard-go включены в установщик. Homebrew и Xcode на целевом Mac не нужны. Эта сборка для Apple Silicon; приложение пока не подписано Developer ID и не нотарифицировано для публичного распространения.

## Возможности

- Импорт `.conf`; имена уникальны без учёта регистра. Одинаковый конфиг под другим именем также отклоняется.
- Независимые туннели; операции с маршрутами/DNS сериализованы, активные соединения работают параллельно.
- Пересечения AllowedIPs (IPv4/IPv6) и несколько DNS-конфигураций отображаются как предупреждения. Системный DNS macOS общий, а маршруты одинаковой длины могут конфликтовать.
- Редактор с валидацией и маскированием PrivateKey/PresharedKey. Маркеры сохраняют старые ключи, новые ключи можно вставить вместо них. Изменять конфиг можно после отключения этого туннеля.
- Состояние и статистика обновляются автоматически: последний handshake, endpoint, AllowedIPs, keepalive, RX/TX. Поднятый интерфейс не доказывает доступность интернета.
- Закрытие окна оставляет клиент в строке меню. Завершение клиента не выключает туннели. Поповер открывается иконкой или ⌘⇧T.
- View Transitions для выбора туннеля и редактора. Обновления состояния и статистики не запускают анимацию всей страницы. Настройка macOS «Уменьшение движения» отключает анимации.

## Данные и системный помощник

Пользовательские профили остаются в Electron userData (`~/Library/Application Support/wireguard-ui/tunnels`): директория 0700, конфиги 0600. Секретные ключи не передаются из сохранённых конфигов в renderer; статистика очищается от private/preshared keys в привилегированном процессе.

Помощник устанавливается для конкретного UID:

- `/Library/PrivilegedHelperTools/local.wireguard.desktop.<UID>` — root-owned код и самостоятельные бинарники;
- `/Library/LaunchDaemons/local.wireguard.desktop.<UID>.plist` — launchd job;
- `/var/run/wireguard-desktop-<UID>/helper.sock` — IPC, доступен только этому UID (0600), директория принадлежит root;
- `/Library/Application Support/WireGuardDesktop/<UID>/tunnels` — root-owned конфиги для надёжного отключения с исходными параметрами маршрутов/DNS.

IPC разрешает только проверку доступности, снимок состояния, включение/выключение валидного профиля и удаление неактивной служебной копии. Произвольные команды, пути, env и shell hooks не принимаются. Запросы проверяются повторно в root-процессе. Код помощника и его зависимости не запускаются из изменяемого пользовательского каталога. Изменение версии помощника может потребовать повторной установки с разрешением администратора.

## Разработка

```sh
npm install
npm run dev
npm run build
npm test
npm run package
npm run dist:mac
```

Для сборки требуется Node.js 20.19+ или 22.12+ (рекомендуется Node 24 LTS).

Для подготовки распространяемого backend на машине сборки нужны Homebrew-пакеты `bash wireguard-tools wireguard-go` и standalone Node (официальный Node/NVM). Скрипт проверяет, что бинарники используют только системные dylib. Для явного выбора Node задайте `WG_NODE_RUNTIME=/path/to/node`.

`npm run dist:mac` создаёт DMG в `release/`; `npm run package` — `.app`. Лицензии backend/runtime включены в `Contents/Resources/helper/licenses`.

Фронтенд организован по FSD (`app → pages → widgets → features → entities → shared`). См. `ARCHITECTURE.md`. Проверка границ импортов встроена в сборку; форматирование: `npm run format`.
