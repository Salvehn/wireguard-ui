# WireGuard Desktop

Клиент WireGuard для macOS на Apple Silicon. Импорт и редактирование конфигов, несколько туннелей, статистика трафика и управление из строки меню.

## Скачать и установить

1. [Скачайте установщик](https://github.com/Salvehn/wireguard-ui/releases/latest/download/WireGuard-Desktop-arm64.dmg) или откройте [последний релиз](https://github.com/Salvehn/wireguard-ui/releases/latest) и выберите DMG в разделе **Assets**.
2. Откройте DMG и перетащите **WireGuard Desktop** в **Applications / Программы**.
3. Запустите приложение и разрешите установку системного помощника. Пароль администратора нужен при его установке; переключение VPN работает без повторных запросов.
4. Нажмите **Добавить туннель**, выберите файл `.conf` и подключитесь.

Приложение пока не подписано Apple. Если macOS блокирует запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** для этого приложения.

Конфиги и ключи хранятся локально. Закрытие окна оставляет приложение в строке меню; выход из приложения не отключает туннели.

## Разработка

Нужны Node.js 22.12+ и npm. Для сборки установщика — standalone Node (например, через NVM) и Homebrew-пакеты `bash`, `wireguard-tools`, `wireguard-go`.

```sh
npm ci
npm run dev       # запуск
npm test          # тесты
npm run build     # проверка и сборка интерфейса
npm run dist:mac  # DMG в release/
```
