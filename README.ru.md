# WireGuard Desktop

**Русский** · [English](README.md) · [Скачать для Mac](https://github.com/Salvehn/wireguard-ui/releases/latest/download/WireGuard-Desktop-arm64.dmg) · [Скачать для Windows](https://github.com/Salvehn/wireguard-ui/releases/latest/download/WireGuard-Desktop-x64-Setup.exe)

Клиент WireGuard для macOS на Apple Silicon и Windows x64. Импортируйте профили `.conf`, подключайте несколько туннелей независимо и следите за трафиком и handshake. Управление доступно в окне и системном трее; конфигурации и ключи остаются на компьютере.

## Split tunneling

Откройте **Smart tunneling** у отключённого профиля и выберите, какой трафик направлять через это соединение. Настройки сохраняются отдельно для каждого профиля и только сужают исходные `AllowedIPs`.

| Режим                       | Трафик через это соединение                                              |
| --------------------------- | ------------------------------------------------------------------------ |
| Маршруты конфигурации       | Маршруты импортированного `.conf`                                        |
| Только адреса из списка     | Выбранные домены, IP-адреса и сети CIDR                                  |
| Кроме адресов из списка     | Исходные маршруты за исключением указанных адресов                       |
| Только выбранные приложения | Процессы внутри выбранных `.app` на macOS или выбранные `.exe` в Windows |
| Кроме выбранных приложений  | Остальные процессы                                                       |

**Домены и поддомены.** `example.com` обозначает сам домен. Маска `*.example.com` охватывает поддомены любого уровня, например `api.example.com` и `a.b.example.com`, но не сам домен. Добавьте обе записи или нажмите **«Поддомены»**, чтобы добавить маску рядом с доменом. Маски получают IPv4/IPv6-адреса из системных DNS-запросов и сохраняют их до отключения. Сайты с общим IP следуют одному адресному правилу; приложения с собственным DNS-over-HTTPS могут обходить маски.

**Приложения и несколько VPN.** Выбирайте `.app` в macOS или `.exe` в Windows через стандартное окно. Правила приложений и адресов — альтернативные режимы одного профиля; разные профили могут одновременно использовать разные режимы. Конкретные рабочие подсети обычных VPN сохраняют приоритет. При совпадении правил приложений используется последнее подключённое соединение. Исключённый или невыбранный трафик может идти через другой активный VPN, а не обязательно напрямую. Отключение одного профиля сохраняет остальные.

Если для домена маски уже есть обычный файл `/etc/resolver`, помощник направляет запросы его DNS-серверам и восстанавливает исходный файл при отключении. Другие пересекающиеся DNS-правила по-прежнему блокируют подключение. Точные домены в зоне маски тоже получают адреса из DNS-запросов: отсутствие записи у корневого домена не мешает подключиться.

**DNS профиля.** В режиме **«Маршруты конфигурации»** строка `DNS` из импортированного `.conf` временно становится системным DNS и восстанавливается при отключении. Выборочные режимы Smart tunneling сохраняют системный DNS. Для масок используются `/etc/resolver` в macOS и правила NRPT в Windows; изменения журналируются и удаляются при отключении или восстановлении.

В режимах со списком адресов используется системный DNS. В режиме приложений DNS следует обычным маршрутам, общие системные службы могут не определяться как часть приложения, а статистика peers WireGuard недоступна. После подключения перезапустите выбранные приложения. Изменения соединений или доменных маршрутов кратко перезапускают общий движок приложений и могут прервать его трафик. Установка или обновление системного помощника требует разрешение администратора. Windows-установщик включает официальный подписанный пакет WireGuard for Windows.

Маски и маршрутизация по приложениям пока экспериментальные. Автоматические проверки охватывают обе платформы; первый Windows-релиз должен также пройти проверку с реальным VPN в Windows.

Есть русский и английский языки, светлая и тёмная темы, обновления через интерфейс с прогрессом загрузки и перезапуском.
